=== 2. Full RAG Pipeline Flowchart ===

flowchart TD
    %% Ingestion Flow
    subgraph Data Ingestion
        A[User Uploads Document] --> B{File Type?}
        B -- PDF/DOCX --> C[File Parser Service]
        B -- URL --> D[Firecrawl Scraper]
        B -- YouTube --> E[Transcript Extractor]
        C --> F[Chunking Service]
        D --> F
        E --> F
        F --> G[Gemini Embedding API]
        G -->|Returns 768-dim Vector| H[(pgvector Database)]
    end

    %% Retrieval Flow
    subgraph Retrieval & Generation
        I[User Asks Question] --> J[Gemini Embedding API]
        J -->|Generates Query Vector| K[Cosine Similarity Search]
        H <-->|Vector Math `<=>`| K
        K -->|Top-K Context Chunks| L[Groq Llama 3.3 LLM]
        I --> L
        L --> M[Synthesized Response]
        M --> N[Next.js Frontend UI]
    end


=== 3. API Flow Sequence Diagram ===

sequenceDiagram
    actor User
    participant Frontend as Next.js Client
    participant Auth as Auth.js
    participant API as /api/chat Route
    participant DB as Neon Postgres (pgvector)
    participant Gemini as Google Gemini API
    participant Groq as Groq Cloud (LLM)

    User->>Frontend: Send Message
    Frontend->>Auth: Check Session Token
    Auth-->>Frontend: Session Valid
    Frontend->>API: POST {message, workspaceId}
    
    API->>DB: Fetch Chat History
    DB-->>API: Returns Previous Messages
    
    API->>Gemini: Send User Message for Embedding
    Gemini-->>API: Returns 768-dim Query Vector
    
    API->>DB: Cosine Similarity Search (Query Vector)
    DB-->>API: Returns Relevant Document Chunks (Context)
    
    API->>Groq: Send Prompt + Context + History
    Groq-->>API: Streamed Text Response
    
    API-->>Frontend: HTTP Stream
    Frontend-->>User: Typing Animation Displays Answer
